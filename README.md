# Diário de Horas — Android

Projeto Android independente do Floot.

Recursos:
- Registro hora a hora.
- Horário inicial e final editável.
- Registros salvos localmente no celular.
- Fechamento manual do dia e relatório.
- Alarme/notificação de hora em hora.
- Não fecha automaticamente à meia-noite.

Para gerar o APK, abra este projeto em Android Studio e execute:
`./gradlew assembleDebug`

O APK será criado em:
`app/build/outputs/apk/debug/app-debug.apk`
